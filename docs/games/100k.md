# 100 к одному

[← Все игры](../../README.md)

Командная викторина в формате телепередачи: ведущий открывает вопросы, команды угадывают самые популярные ответы, а табло считает очки.

| Параметр | Значение |
|---|---|
| Игроков | 2–8 |
| Длительность | 40–60 минут |
| Порт | `8101` |
| Формат | 2 команды, ведущий, общий экран |

## Как играют

1. Ведущий создаёт комнату и открывает админ-панель.
2. Игроки подключаются с телефонов по QR-коду с общего экрана.
3. Ведущий запускает раунды: face-off, вопросы, обратный раунд и большой вопрос.
4. Табло показывает счёт, текущий вопрос и состояние команд.

## Роли

- **Ведущий** — создаёт игру, открывает вопросы, принимает ответы.
- **Экран** — общее табло для телевизора или проектора.
- **Игроки** — отвечают со своих телефонов.

## Экраны

| Страница | Адрес |
|---|---|
| Вход и создание игры | `http://<LAN-IP>:8101/` |
| Панель ведущего | `http://<LAN-IP>:8101/admin` |
| Общий экран | `http://<LAN-IP>:8101/display` |
| Телефон игрока | `http://<LAN-IP>:8101/player` |

## Запуск

```bat
cd games\100k
npm install
npm start
```

Или из корня платформы: `start.bat`, затем откройте карточку игры на портале.

## Данные

Паки вопросов лежат в `games/100k/questions/`. История и комнаты хранятся в памяти и не пишутся в базу.
