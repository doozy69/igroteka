# Новая игра

Инструкция для человека и готовый промпт для агента.

## Промпт для агента

Скопируй текст, заменив поля в фигурных скобках, и отдай агенту. Этого достаточно: агенту не нужно читать другие игры.

```text
Ты работаешь в D:\igroteka — платформа локальных игр.

Создай новую игру:
- название: {НАЗВАНИЕ}
- id: {id} (латиница, нижний регистр, без пробелов)
- порт: {порт} (свободный из 8104–8199)
- механика: {КОРОТКОЕ ОПИСАНИЕ ПРАВИЛ}
- игроков: {2–8}
- длительность: {30–60 мин}
- акцентный цвет: {#RRGGBB}
- монограмма: {1–3 символа}

Сначала прочитай только эти файлы:
1. AGENTS.md
2. docs/CONTRACT.md
3. docs/NEW_GAME.md
4. games/_template/AGENTS.md

Не читай games/100k, games/svoy, games/quiz и их код: они не нужны для задачи.

Порядок работы:
1. Скопируй games/_template в games/{id}.
2. Переименуй проект в package.json, замени тексты шаблона.
3. Реализуй сервер и клиент внутри games/{id}. Игра должна работать сама по себе.
4. Добавь запись в games.json. Код apps/portal не меняй.
5. Запусти npm run validate и исправь замечания.
6. Установи зависимости и проверь одиночный запуск на порту {порт}.
7. Запусти платформу, проверь карточку на портале и подключение с телефона по LAN.
8. Обнови games/{id}/AGENTS.md и README игры.

Соблюдай контракт:
- process.env.PORT и прослушивание 0.0.0.0;
- свои data/ и questions/, без доступа к чужим;
- никаких импортов из других игр;
- health-эндпоинт /api/health;
- QR и join-ссылки — на LAN-IP, не на localhost;
- фиксированный порт, без автопоиска.

В конце покажи:
- какие файлы созданы;
- как запустить игру отдельно;
- как проверить её на телефоне;
- результаты проверок.
```

## Что считается готовой игрой

- [ ] `games/<id>/` — самостоятельный проект с `package.json`.
- [ ] `npm install && npm start` в папке игры работает без платформы.
- [ ] `PORT` из окружения учитывается, сервер слушает `0.0.0.0`.
- [ ] В `games.json` добавлена запись, порт совпадает с конфигом.
- [ ] Портал показывает карточку, статус и ссылку без правок своего кода.
- [ ] QR/join-ссылка ведёт на LAN-IP, а не на `localhost`.
- [ ] Данные и паки лежат внутри игры.
- [ ] Нет импортов и чтения файлов из других игр.
- [ ] `AGENTS.md` игры описывает запуск, структуру и инварианты.
- [ ] Проверено на телефоне в той же Wi-Fi сети.

## Шаги для человека

### 1. Выберите id и порт

`id` — короткий ASCII-slug: `alias`, `crocodile`, `mafia`. Он попадёт в логи и атрибуты DOM.

Порты:

| Игра | Порт |
|---|---|
| портал | 8080 |
| 100 к одному | 8101 |
| Своя игра | 8102 |
| Кто быстрее | 8103 |
| новая игра | 8104–8199 |

### 2. Скопируйте шаблон

```bat
cd D:\igroteka
xcopy games\_template games\alias /E /I
```

Или в PowerShell:

```powershell
Copy-Item -Recurse games\_template games\alias
```

### 3. Реализуйте игру

Минимум, который даёт шаблон:

- Express + Socket.IO;
- `/api/health`;
- `/api/net` с LAN-IP;
- отдача статики;
- подключение сокета и проверка связи;
- корректная остановка.

Дальше добавляйте комнаты, игроков, раунды — всё внутри папки игры.

### 4. Добавьте запись в `games.json`

```json
{
  "id": "alias",
  "title": "Alias",
  "tagline": "Объясни слово, не называя его",
  "description": "Команды объясняют слова за ограниченное время.",
  "dir": "games/alias",
  "port": 8104,
  "players": "4–12",
  "duration": "30–60 мин",
  "tags": ["команды", "слова"],
  "accent": "#8bd450",
  "monogram": "A",
  "status": "ready"
}
```

Портал сам нарисует карточку. Если для этого пришлось править `apps/portal`, значит игра выходит за контракт.

### 5. Проверьте контракт

```bat
cd D:\igroteka
npm run validate
```

Скрипт проверит запись в `games.json`, папку, `package.json`, `npm start` и `AGENTS.md`.

### 6. Проверьте отдельно

```bat
cd games\alias
npm install
npm start
```

Откройте `http://localhost:8104/`. Убедитесь, что `http://localhost:8104/api/health` отвечает `ok`.

### 7. Проверьте в платформе

```bat
cd D:\igroteka
start.bat
```

На портале должна появиться карточка со статусом «в сети». Откройте её, создайте комнату, подключитесь с телефона по QR.

### 8. Проверьте LAN

- Откройте портал по адресу `http://192.168.x.x:8080/`, а не по `localhost`.
- QR должен содержать LAN-IP.
- Телефон в той же сети должен открыть игру.

## Частые ошибки

- **Ссылка ведёт на localhost.** Не стройте join-URL из `location.origin` на машине ведущего. Берите LAN-IP с сервера.
- **Игра работает только внутри платформы.** Значит, граница фиктивная. Сначала добейтесь одиночного запуска.
- **Порт «плавает».** Отключите автопоиск. Платформа требует стабильный адрес.
- **Общий код появился сам собой.** Импорт из соседней игры — запрещён. Нужен общий модуль — сначала `packages/` и отдельное решение.
- **Данные в корне платформы.** Всё, что создаёт игра, должно лежать в её `data/`.
- **Правка портала под новую игру.** Это сигнал, что контракт неполный. Остановитесь и опишите нехватку.
