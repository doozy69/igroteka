# AGENTS.md — портал «Игротека»

Тонкая общая панель. Здесь нет кода игр и не должно быть.

## Запуск

```bat
npm install
npm start
```

Порт по умолчанию — `8080`, переопределяется через `PORT`. Платформа запускает портал так же. Правки HTML/CSS/JS в `public/` не требуют перезапуска — только обновление вкладки.

## Структура

| Путь | Что это |
|---|---|
| `server.mjs` | Node-сервер: статика, `/api/games`, `/api/net`, `/qr` |
| `public/index.html` | разметка |
| `public/style.css` | оформление |
| `public/app.js` | карточки, статусы, QR, копирование адреса |
| `../../games.json` | реестр игр, не редактируется из портала |

## Эндпоинты

- `GET /api/games` — читает корневой `games.json`, добавляет вычисляемое `online` (TCP-проверка порта).
- `GET /api/net` — LAN-адреса и порт портала.
- `GET /qr?text=...` — SVG QR.

## Правила

- Портал **не импортирует** код игр и не читает их `data/`.
- Список игр не хардкодится в JS/HTML. Он приходит из `games.json`.
- Добавление игры не должно требовать правок портала. Если требует — сначала обнови контракт в `docs/CONTRACT.md` и обоснуй.
- Ссылки на игры строятся как `<protocol>//<hostname>:<port>/`. `localhost` допустим только когда пользователь сам открыл портал на localhost; для гостей есть QR с LAN-IP.
- Статус обновляется раз в 5 секунд; не превращай это в тяжёлый мониторинг.
- Внешних CDN, шрифтов и аналитики нет: платформа должна работать без интернета.
- Дизайн: тёмный «игровой вечер», крупная типографика, акцентный цвет каждой игры из `accent`, адаптив до 360 px. Не превращай панель в дашборд.

## Проверки

```bat
node --check server.mjs
```

Затем запусти платформу и проверь:

- три карточки;
- статусы «в сети»;
- переход в каждую игру;
- QR открывается и содержит LAN-IP;
- копирование адреса;
- мобильную ширину.
