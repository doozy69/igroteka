# AGENTS.md — «Кто быстрее» (Quiz Lite)

Самостоятельная игра. Работай только в этой папке.

## Запуск

```bat
npm install
npm start
```

Порт по умолчанию — `8103`, переопределяется через `PORT`. Платформа запускает игру тем же способом и выставляет `AUTO_OPEN=false`. Фронтенд в `public/` не требует перезапуска — только обновление вкладки.

## Структура

| Путь | Что это |
|---|---|
| `server/index.js` | точка входа, конфиг, порт, браузер |
| `server/app.js` | Express, Socket.IO, `/api/health`, статика |
| `server/game.js` | игровая логика |
| `server/rooms.js` | комнаты |
| `server/history.js` | история матчей |
| `server/util.js` | LAN-адреса и нормализация |
| `public/` | экран, комната, ТВ, история |
| `data/history.json` | история, создаётся при работе |
| `config.json` | порт, лимиты, `autoPort` |
| `test/` | тесты |

## Контракт

- `/api/health` → `{ status, version, uptime, rooms }`.
- `/api/rooms`, `/api/room/:code`, `/api/history`.
- Socket.IO на стандартном пути `/socket.io/`.
- Join-ссылки строятся на сервере из LAN-адресов.

## Инварианты

- `config.json`: `autoPort` выключен. Порт должен быть стабильным, иначе ссылки и QR уедут.
- `AUTO_OPEN=false` отключает открытие браузера при запуске из платформы.
- ESM-проект (`"type": "module"`), Node 22+.
- История лежит в `data/history.json`; не переноси её в корень платформы.
- Никаких импортов из других игр.

## Тесты

```bat
npm test
```

Это `node --test`. Если меняешь чистую логику, добавляй тест рядом.

## Если появится reverse proxy

Socket.IO и статика используют корень origin. При монтировании в подпуть нужно синхронно поменять `path` на сервере и у клиента `io({ path })`, а также проверить абсолютные пути в HTML.
