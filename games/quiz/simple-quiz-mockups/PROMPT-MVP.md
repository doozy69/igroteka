# 🚀 Simple Quiz — MVP (Минимально жизнеспособный продукт)

## Концепция
**Один экран — одна цель**: определить, кто быстрее нажал кнопку «Я знаю!», когда появился вопрос.

---

## Что убрали (сложное → простое)

### ❌ Удалено
- История игр (`/history`)
- ТВ-табло (`/r/:code/display`)
- Админка с редактированием вопросов
- Разные типы игр (только "кто быстрей")
- Сложный роутинг комнат
- Долгий цикл: создание → лобби → игра → результаты

### ✅ Оставлено (критично!)
- Главная (`/`): список игр / создать игру
- Лобби (`/game/:id`): ожидание игроков
- **Главный экран — Приём ответов (`/r/:code`)**: огромная кнопка, очередь
- Итоги (`/result`): кто победил, таблица результатов

## Протокол сокета (минимум)

### Создаём игру
```
Клиент → Сервер: { type: "createGame", question, timeLimit }
Сервер → Клиент: { gameId, code }
```

### Старт раунда
```
Сервер → Все игроки: { event: "startRound", question, buzzOpen: true }
```

### Игрок нажал кнопку
```
Клиент (любой) → Сервер: { type: "buzz", playerColor }
Сервер → Все: { event: "playerBuzzed", name, color, offsetMs }
```

### Ведущий принимает вердикт
```
Игрок (ведущий) → Сервер: { type: "verdict", isCorrect, playerColor }
Сервер → Все: { event: "roundFinished", winner, scores, verdict }
```
