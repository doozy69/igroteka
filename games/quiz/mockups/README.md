# Макеты: LAN-викторина «Кто быстрее» (lite)

Дизайн-референс к `prompt-quiz-lite.md`. В прод-код и релиз не попадают.

## Как посмотреть

**Быстро:** открыть любой `*.html` в браузере.

**С локального сервера** (удобно для сравнения на телефоне):

```powershell
node mockups/serve.mjs 8899
```

Затем `http://127.0.0.1:8899/01-home.html`.

Шрифт: `system-ui, "Segoe UI", Roboto, sans-serif`. Иконки — эмодзи и текст, без библиотек.

## Правила

- Тёмная тема, мобильный first.
- Кнопка «Я знаю!» — не меньше трети экрана, крупный шрифт, нижняя часть.
- Тайминги — моноширинный `tabular-nums` и всегда с двумя знаками: `0.00 с`, `+0.42 с`.
- Никаких внешних шрифтов, CDN и картинок: всё рисуется CSS.
- Пиксельного соответствия не требуется, важен состав блоков и иерархия.

## Пересборка PNG

Скриншоты сняты headless Chrome:

```powershell
$chrome = "C:\Program Files\Google\Chrome\Application\chrome.exe"
& $chrome --headless=new --disable-gpu --hide-scrollbars `
  --force-device-scale-factor=2 --window-size=390,844 `
  --screenshot="mockups\01-home.png" --user-data-dir="$env:TEMP\shot-01" `
  "http://127.0.0.1:8899/01-home.html"
```

Для ТВ: `--window-size=1920,1080` без `--force-device-scale-factor`.
