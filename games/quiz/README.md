# Кто быстрее — LAN-викторина

Минимальная версия викторины для игры в одной комнате по локальной сети. Ведущий читает вопрос,
игроки жмут «Я знаю!», сервер определяет порядок нажатий и считает очки. Интернет и CDN не нужны.

## Быстрый старт

```bash
npm install
npm start
```

На Windows можно просто дважды кликнуть `start.bat` — он сам переходит в папку проекта, при первом
запуске устанавливает зависимости и открывает браузер.

После запуска в консоли появятся адреса:

```
  Кто быстрее v1.0.0
  Локально:  http://localhost:8103
  Телефоны:  http://192.168.1.10:8103
  История:   ...\data\history.json
```

Браузер ведущего откроется автоматически (`autoOpenBrowser` в `config.json`). Телефоны подключаются
по адресу из строки «Телефоны» — они должны быть в той же Wi-Fi/LAN-сети.

Требуется Node.js 22 или новее.

## Как играть

1. Ведущий открывает главную страницу, вводит название комнаты и свой ник, нажимает
   **«Создать и играть»**. Появляется код из 4 символов.
2. Игроки открывают тот же адрес, вводят код и ник, нажимают **«Войти»**.
   В главном списке **«Открытые комнаты»** уже есть готовые комнаты текущей сети —
   достаточно нажать на нужную кнопку: код подставится в форму входа автоматически.
3. Ведущий нажимает **«Начать игру»**.
4. В фазе вопроса ведущий читает вопрос вслух (текст можно ввести в поле — его увидят все).
5. **«Принимаю ответы»** открывает приём нажатий. Все игроки жмут большую кнопку **«Я знаю!»**.
6. В очереди виден порядок и отставание: `0.00 с`, `+0.42 с`, `+0.91 с`.
7. Ведущий ставит вердикт текущему лидеру: **«Верно +1»** или **«Неверно»**. После «Неверно»
   ход переходит к следующему нажавшему; после «Верно» раунд завершается.
8. **«Следующий вопрос»** начинает новый раунд.
9. **«Завершить игру»** сохраняет матч в JSON-файл и показывает итоговую таблицу.

Ведущий тоже играет. Игроки и ведущий могут открыть табло `/r/<код>/tv` на общем экране или
телевизоре — оно обновляется автоматически.

Если страницу случайно закрыли, достаточно открыть адрес комнаты снова: игрок определяется по
`localStorage`, ник и очки сохранятся. У ведущего права тоже привязаны к его браузеру.

## История

Матчи лежат в `data/history.json`. Список доступен на `/history`, детали матча — на `/history/<id>`.

Чтобы очистить историю:

1. Остановите сервер (`Ctrl+C`).
2. Удалите `data/history.json` (или весь файл, или только нужные записи).
3. Запустите сервер снова.

Если удалить файл при работающем сервере, архив в памяти останется до перезапуска. Файл перезаписывается
атомарно (`.tmp` + `rename`), поэтому обрыв питания не оставит «половину» JSON. Хранятся последние
200 матчей (`historyLimit`).

## Настройки

`config.json` в корне проекта:

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `port` | `8103` | Начальный порт |
| `maxPlayers` | `12` | Максимум игроков в комнате |
| `historyLimit` | `200` | Сколько матчей хранить в файле |
| `autoOpenBrowser` | `true` | Открывать браузер при старте |

Флаги командной строки:

```bash
npm start -- --port 8080     # другой порт
npm start -- --no-open       # не открывать браузер
npm start -- --history data/other.json
```

Переменные окружения `PORT`, `MAX_PLAYERS`, `AUTO_OPEN=false`, `HISTORY_FILE` работают так же.

Если порт занят, сервер попробует следующие 20 портов и напишет фактический адрес в консоль.

## Если что-то не работает

**Порт занят.** Сервер сам берёт следующий свободный порт (до 20 попыток) и печатает его в консоли.
Можно задать другой: `npm start -- --port 8080`.

**С телефона не открывается.** Проверьте, что телефон и компьютер в одной сети (не гостевой Wi-Fi),
используйте адрес из строки «Телефоны», а не `localhost`. Разрешите Node.js в брандмауэре Windows:

```powershell
New-NetFirewallRule -DisplayName "Quiz Lite 8103" -Direction Inbound -Protocol TCP -LocalPort 8103 -Action Allow
```

**«Не удаётся подключиться» после долгой паузы.** Комнаты живут 6 часов без активности. Создайте новую.

**История пустая.** Игра ещё не завершалась кнопкой «Завершить игру» — матч сохраняется только в этот
момент. Проверьте, что `data/history.json` существует и содержит корректный JSON.

**Браузер кэширует старую версию.** Обновите страницу с `Ctrl+F5`.
