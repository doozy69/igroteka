# AGENTS.md — «100 к одному»

Самостоятельная игра. Работай только в этой папке.

## Запуск

```bat
npm install
npm start
```

Порт по умолчанию — `8101`, переопределяется через `PORT`. Платформа запускает игру тем же способом. Фронтенд в `public/` не требует перезапуска — только обновление вкладки.

## Структура

| Путь | Что это |
|---|---|
| `server.js` | HTTP-сервер, комнаты, WebSocket на `/ws`, `/api/health`, `/api/net`, `/qr` |
| `server/game/engine.js` | игровая логика |
| `public/index.html` | вход/лобби |
| `public/admin.html` | ведущий |
| `public/display.html` | общий экран |
| `public/player.html` | телефон игрока |
| `public/js/` | клиенты, звук, общие функции |
| `public/css/style.css` | стили |
| `questions/*.json` | паки вопросов |
| `game.config.json` | настройки, JSON с комментариями |

## Контракт

- `/api/health` → `{ status, game, uptime, rooms }`.
- `/api/net` → LAN-IP и порт; используется для QR и адреса гостей.
- `/qr?text=...` → SVG QR.
- WebSocket: `ws://<host>/ws`.
- Страницы: `/`, `/admin`, `/display`, `/player`.

## Инварианты

- Не меняй путь `/ws`: клиент в `public/js/common.js` собирает его от `location.host`.
- Не меняй формат паков без миграции существующих файлов.
- Комнаты хранятся в памяти; диска с состоянием нет. Не добавляй БД без отдельного решения.
- Все вопросы и настройки остаются внутри этой папки.
- Никаких импортов из `games/svoy`, `games/quiz` или `apps/portal`.

## Особенности

- При занятом порте сервер умеет искать следующий. Платформа этого не хочет: лаунчер заранее проверяет порт и падает с ошибкой. Не полагайся на автопоиск в платформенном режиме.
- `game.config.json` намеренно содержит комментарии; парсер в `server.js` их вырезает. Не переводи файл в строгий JSON без необходимости.
- LAN-адрес выбирается эвристикой по `192.168.*`, `10.*`, `172.16–31.*`.
