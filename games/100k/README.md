# «100 к одному» — веб-версия

Командная игра по мотивам телешоу: ведущий управляет с ноутбука, на телевизоре
открыто табло с переворачивающимися плашками, игроки подключаются с телефонов.
Ответы игроки произносят вслух, а ведущий не вводит текст — он **открывает нужную
карточку** или ставит страйк.

- **Backend:** Node.js + `ws` (WebSocket), без базы данных.
- **Контент:** JSON-паки вопросов в папке `questions/`.
- **Состояние:** в памяти сервера, отдельно для каждой комнаты.
- **Интерфейсы:** главная (лобби), панель ведущего, экран для ТВ, страница игрока.

## Возможности

- Одна точка входа: на главной создают игру и подключаются игроки.
- Комнаты с кодом, списком активных игр и QR-кодом на ТВ.
- **Капитаны:** первый игрок команды; админ может назначить другого.
- **Порядок игроков:** капитан всегда первый; админ меняет порядок остальных
  кнопками ↑/↓. Порядок виден на ТВ, в админке и на телефонах.
- **Розыгрыш с кнопкой:** участники видят на телефоне кнопку «Я отвечаю!»;
  первый нажавший показывается на ТВ. Ведущий открывает карточку, которую назвал
  участник, или отмечает «Мимо».
- **Вопрос показывается только после кнопки ведущего** «Показать вопрос / Приём ответов»:
  сначала ведущий читает его вслух, потом вопрос появляется на ТВ и телефонах.
- **Очередь ответов:** на ТВ и телефонах видно, кто отвечает сейчас. После ответа
  очередь переходит к следующему игроку; ведущий может поправить её кнопкой ▶
  или «Следующий».
- **Блиц-опрос:** после трёх страйков ведущий спрашивает четыре версии и открывает
  карточку, которую выбрал капитан, либо «Мимо».
- **Игра наоборот:** инструкция → ведущий читает вопрос → кнопка «Показать вопрос
  и запустить таймер» → вопрос и таймер 20 секунд на всех экранах → ведущий выбирает
  версии команд, фиксирует их, а затем открывает любые карточки. После раунда
  показывается победитель основной игры.
- **Большая игра:** два игрока, пять вопросов (текст видит только ведущий), ответы
  выбираются кнопками-чипами, отдельные таймеры для каждого игрока, два этапа
  проверки, дубли обнуляются, в конце — вывод «выиграли / не выиграли».
- **Финальные итоги:** после завершения игры на одном экране показывается таблица
  всех блоков с вопросами и ответами, а также результаты большой игры: вопросы,
  все возможные ответы с очками и ответы обоих игроков.
- **Правила и подсказки:** на ТВ, в админке и на телефонах.
- Название раунда («Простая», «Двойная», «Тройная», «Игра наоборот», «Большая игра»)
  выводится на всех экранах; шрифты на ТВ и телефонах увеличены.
- Скрытые ответы не уходят на ТВ и телефоны до открытия; обычный вопрос не уходит
  до показа, а вопросы большой игры на ТВ и телефонах не выводятся вообще.
- Переподключение по токену, автоматический выбор свободного порта, звуки на ТВ.

## Запуск

```bash
npm install
npm start
```

Откройте `http://localhost:8101`.

Если порт 8101 занят, сервер автоматически выберет следующий свободный
(3101, 3102, …) и напишет точный адрес в консоли.

1. На главной введите название игры и нажмите **«Создать комнату»**.
2. В панели ведущего нажмите **«Экран для ТВ»** — откройте в отдельном окне.
3. Игроки открывают ту же главную страницу (или сканируют QR с ТВ), вводят имя,
   выбирают команду и нажимают **«Войти»**.
4. Ведущий выбирает пак и нажимает **«Начать игру»**.

Если играют с разных устройств в одной сети, используйте IP-адрес компьютера
с сервером, например `http://192.0.2.10:8101`.

## Как вести игру

### Подготовка

- В блоке **«Команды»** видны составы. Номера — это порядок ответов.
- **Первый игрок — капитан (★).** Если админ назначает капитаном другого игрока,
  тот перемещается на первое место; остальные сохраняют порядок. Выше капитана
  поднять никого нельзя.
- Админ меняет порядок остальных кнопками **↑ / ↓**.
- Игроки меняют команду сами до старта; админ может переводить их кнопкой
  **«→ Команда …»** в любой момент, кроме завершённой игры.
- Если игрок уходит из команды, капитан переназначается автоматически.

### Розыгрыш

1. Сервер выбирает участников по порядку:
   - **простая игра** — капитан (позиция 1);
   - **двойная игра** — второй игрок;
   - **тройная игра** — третий игрок.
   Если игрок уже участвовал в предыдущем розыгрыше, берётся следующий по порядку.
   Админ может поменять участников в блоке **«Розыгрыш»**.
2. Ведущий видит вопрос в своей панели, читает его вслух и нажимает
   **«Показать вопрос / Приём ответов»**.
3. После этого вопрос появляется на ТВ и телефонах, а участники получают кнопку
   **«Я отвечаю!»**.
4. Кто нажал первым — показывается на ТВ и в админке.
5. Ведущий нажимает карточку, которую назвал участник, или **«Мимо»**.
   - Если это первый по популярности ответ — команда сразу получает контроль.
   - Иначе отвечает второй участник. Если его карточка популярнее — контроль
     переходит к его команде, иначе остаётся у первой.
   - Если оба промахнулись — **«Следующие участники»**.
6. После определения команды начинается основная часть.

### Основная часть и очередь

- На ТВ и телефонах показывается **«Сейчас отвечает: …»**.
- Очередь начинается со следующего игрока после того, кто отвечал в розыгрыше.
- Ведущий нажимает карточку, которую назвал текущий игрок. Очередь автоматически
  переходит к следующему. Промах — кнопка **«Страйк»** (очередь тоже переходит).
- Ведущий может поставить очередь на конкретного игрока кнопкой **▶** в составе
  или сдвинуть её кнопкой **«Следующий»**.
- Три страйка → блиц-опрос.

### Блиц-опрос

- Ведущий спрашивает четыре версии у команды соперников, начиная с последнего
  игрока в порядке состава.
- Затем нажимает карточку, которую выбрал капитан, или **«Мимо»**.
- Если карточка открылась — банк уходит команде блица; если «Мимо» — остаётся
  у контролирующей команды.

### Игра наоборот

1. На всех экранах появляется инструкция: сейчас будет игра наоборот.
2. Ведущий читает вопрос вслух и нажимает **«Показать вопрос и запустить таймер»**.
3. Вопрос появляется на ТВ и телефонах, запускается таймер 20 секунд — он виден
   на всех экранах.
4. Ведущий выбирает версии команд (или «мимо») и нажимает
   **«Зафиксировать версии»**. Одинаковые версии сервер не принимает.
5. Ответы и очки в этот момент ещё скрыты: интрига сохраняется.
6. После фиксации ведущий видит все шесть карточек и открывает их по одной.
   Очки начисляются за карточки выбранных версий.
7. Раунд завершается только после открытия всех шести карточек — заранее
   завершить его нельзя.
8. После раунда на всех экранах показывается, какая команда выиграла основную игру.
9. Очки: 15/30/60/120/180/240 за строки.

### Большая игра

1. Выберите двух игроков (обычно из команды-победителя).
2. Вопросы видит только ведущий: на ТВ и телефонах вместо текста — «Вопрос 1…5».
3. Для каждого вопроса нажмите кнопку-чип с ответом игрока 1 и нажмите
   **«Проверить игрока 1»**. На ТВ после этого видны только очки первого игрока.
4. При необходимости выберите время и запустите отдельный таймер игрока 1 или
   игрока 2 — отсчёт виден на всех экранах.
5. Затем выберите ответы игрока 2 и нажмите **«Проверить игрока 2»**.
6. Ответы, которые уже назвал первый игрок, в колонке второго отмечены серыми
   и недоступны: выбрать повтор нельзя. При попытке нажать серую кнопку звучит
   сигнал повтора. Если второй всё же повторил ответ, при проверке он обнуляется.
7. После проверки второго игрока на ТВ появляются ответы и очки обоих игроков,
   а также вывод «Цель достигнута / Цель не достигнута».
8. Цель — 200 очков. Большая игра финальная: следующий раунд начать нельзя,
   нажмите **«Завершить»** для итогов.

> Табло большой игры — это 5 вопросов и два игрока. Для каждого вопроса в паке
> задаётся список популярных ответов; на табло показываются ответы обоих игроков
> и очки за них. Текст вопросов на ТВ не выводится: их зачитывает ведущий.

## Реализованные правила и ограничения

Реализовано:

- капитаны, порядок игроков и смена капитана;
- розыгрыш с кнопкой, показом вопроса только после команды ведущего, первым/вторым
  ответом по карточкам и повтором;
- основная игра с очередью ответов и автоматическим переходом хода;
- три страйка и блиц-опрос с карточкой капитана;
- игра наоборот с инструкцией, таймером 20 секунд, выбором карточек, отдельной
  фиксацией версий и обязательным открытием всех шести карточек ведущим;
- большая игра с кнопками-чипами, скрытыми от ТВ вопросами, двумя этапами,
  блокировкой повторов после первого игрока, отдельными таймерами игроков,
  сигналом повтора и итогом «выиграли / нет»;
- финальная большая игра: следующий раунд после неё начать нельзя;
- после игры наоборот показывается победитель основной игры;
- финальный экран с таблицей всех блоков (вопросы, ответы, очки) и результатами
  большой игры — в рамках одного экрана, без прокрутки; у большой игры показаны
  вопросы, все возможные ответы с очками и ответы игроков;
- составы, капитаны и очередь на ТВ, в админке и на телефонах;
- подсказки «что делать» на всех интерфейсах;
- название раунда и увеличенные шрифты на ТВ и телефонах.

Пока не автоматизировано:

- приложение показывает очередь, но не запрещает ведущему открыть карточку
  не для того игрока — очередь можно поправить кнопкой ▶/«Следующий»;
- четыре версии блиц-опроса не сохраняются в отдельные поля — ведущий собирает
  их вслух, в приложении открывается итоговая карточка капитана;
- главный приз, супер-игра и денежный фонд не моделируются; победитель основной
  игры определяется по очкам после игры наоборот, результат большой игры
  показывается отдельно;
- ничья после игры наоборот не разыгрывается «камень-ножницы-бумага»;
- размер команд не ограничен пятью игроками.

## Формат паков вопросов

Пак — JSON-файл в `questions/`. Название файла показывается в списке паков,
поле `title` — красивое название.

```json
{
  "title": "Демо-пак",
  "rounds": [
    {
      "type": "simple",
      "text": "Что люди берут с собой в отпуск?",
      "answers": [
        { "text": "Чемодан", "points": 32, "aliases": ["сумка", "багаж"] },
        { "text": "Паспорт", "points": 24, "aliases": ["документы"] }
      ]
    },
    {
      "type": "big",
      "questions": [
        {
          "text": "Что можно забыть дома?",
          "answers": [
            { "text": "Ключи", "points": 45, "aliases": ["ключ"] },
            { "text": "Телефон", "points": 30, "aliases": ["смартфон"] }
          ]
        }
      ]
    }
  ]
}
```

Правила:

- `type`: `simple` | `double` | `triple` | `reverse` | `big`.
- Для `simple`, `double`, `triple`, `reverse` нужно **ровно 6 ответов**.
  `double` и `triple` умножают очки на 2 и 3.
- `reverse` — очки за строки берутся из `game.reversePointsByRank`
  (15/30/60/120/180/240).
- `big` — ровно **5 вопросов**, у каждого — список популярных ответов
  (рекомендуется 5). Очки — число опрошенных.
- `aliases` оставлены в формате как подсказка для ведущего; **автоматического
  сопоставления текста больше нет** — ведущий открывает карточку сам.
- После добавления файла он сразу появляется в списке паков.

Готовые примеры: `questions/demo.json`, `questions/classic.json`.

## Настройки (`game.config.json`)

Файл поддерживает комментарии `//` и `/* */` и читается один раз при запуске.

- `port` — предпочитаемый порт (если занят, берётся следующий свободный);
- `questionsDir` — папка с паками (по умолчанию `questions`);
- `game.defaultTeams` — команды и их названия по умолчанию;
- `game.bigGameTarget` — порог большой игры (обычно 200);
- `game.maxStrikes` — число страйков до блиц-опроса;
- `game.reversePointsByRank` — очки за строки в игре наоборот;
- `game.timers.reverseDiscussionSec` — время совещания в игре наоборот;
- `game.timers.bigGamePlayer1Sec` / `bigGamePlayer2Sec` — время по умолчанию для
  таймеров первого и второго игрока (ведущий может выбрать другое в панели);
- `sound.enabled` — звуки на ТВ;
- `sound.volume` — громкость 0…1.

## WebSocket-протокол

Сообщения: `{ "type": "...", "payload": { ... } }`.

Клиент → сервер:

- `LOBBY_SUBSCRIBE` — подписка на список комнат и паков;
- `ADMIN_CREATE_ROOM` `{ name }` → `ROOM_CREATED` `{ roomId, adminToken }`;
- `ADMIN_JOIN` `{ roomId, adminToken }`;
- `DISPLAY_JOIN` `{ roomId }`;
- `PLAYER_JOIN` `{ roomId, name, teamId, playerId?, playerToken? }`;
- `PLAYER_BUZZ` — нажатие кнопки в розыгрыше;
- `PLAYER_SET_TEAM` `{ teamId }` — смена команды до старта;
- действия администратора:
  - `ADMIN_LOAD_PACK`, `ADMIN_START_ROUND`, `ADMIN_SHOW_QUESTION`;
  - `ADMIN_REVEAL` `{ index }` — открыть карточку (в розыгрыше, игре или блице);
  - `ADMIN_FACEOFF_MISS`, `ADMIN_STEAL_MISS`;
  - `ADMIN_ADD_STRIKE`, `ADMIN_CLEAR_STRIKE`, `ADMIN_AWARD_FUND`;
  - `ADMIN_SET_TURN` `{ playerId }`, `ADMIN_NEXT_TURN`;
  - `ADMIN_REVERSE_CHOICE` `{ teamId, index }`, `ADMIN_LOCK_REVERSE`,
    `ADMIN_REVEAL_REVERSE` `{ index }`;
  - `ADMIN_BIG_PLAYERS` `{ player1Id, player2Id }`,
    `ADMIN_BIG_CHOICE` `{ step, qIndex, choice }`,
    `ADMIN_BIG_TIMER` `{ player, seconds }`, `ADMIN_BIG_TIMER_STOP`,
    `ADMIN_BIG_CHECK1`, `ADMIN_BIG_CHECK2`,
    `ADMIN_BIG_DUPLICATE`, `ADMIN_BIG_SCORE`;
  - `ADMIN_SET_CAPTAIN` `{ teamId, playerId }`;
  - `ADMIN_REORDER_LINEUP` `{ teamId, playerId, direction }`;
  - `ADMIN_SET_FACEOFF_PLAYER` `{ teamId, playerId }`;
  - `ADMIN_RESET_BUZZ`, `ADMIN_NEXT_FACEOFF`;
  - `ADMIN_MOVE_PLAYER` `{ playerId, teamId }`;
  - `ADMIN_SET_TEAM_NAME`, `ADMIN_SET_SCORE`, `ADMIN_FINISH`, `ADMIN_RESET`.

Сервер → клиент:

- `ROOM_STATE` — полное состояние комнаты, отфильтрованное по роли
  (вопрос и скрытые ответы не уходят на ТВ и телефоны до показа; в состоянии есть
  `mainWinner` и `history` для итогов);
- `ROOMS_LIST`, `PACKS_LIST`, `CONFIG` — данные для лобби;
- `TEAM_CHANGED` `{ teamId }` — подтверждение смены команды;
- `EVENT` `{ name }` — звуки на ТВ: `round`, `question`, `reveal`, `strike`,
  `buzz`, `control`, `duplicate`, `win`;
- `ERROR` `{ message }`.

Сервер — источник истины: все изменения применяются на нём и рассылаются клиентам.

## Примечания

- Проект рассчитан на 2 команды и одну игру в комнате; комнат может быть несколько.
- Состояние хранится в памяти: при перезапуске сервера комнаты сбрасываются.
- Пустые комнаты удаляются через 2 часа, завершённые — через 30 минут.
- Доступ администратора подтверждается токеном в `sessionStorage` вкладки.
- Для публичного использования стоит усилить авторизацию и валидацию.
