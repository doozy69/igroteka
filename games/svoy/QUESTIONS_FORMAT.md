# Формат файла вопросов для «Своей игры»

Файлы паков вопросов хранятся в папке `questions/` в формате JSON (кодировка UTF-8).  
Администратор выбирает нужный файл на панели администратора.

Пак проверяется при загрузке: сервер сообщит об ошибке, если структура не соответствует
описанию ниже (например, не 6 категорий или в категории не 5 вопросов).

## Общая структура

```json
{
  "title": "Название пака",
  "round1": {
    "name": "Первый раунд",
    "categories": [ /* 6 категорий */ ]
  },
  "round2": {
    "name": "Второй раунд",
    "categories": [ /* 6 категорий */ ]
  },
  "round3": {
    "name": "Третий раунд",
    "categories": [ /* 6 категорий */ ]
  },
  "final": {
    "themes": [ /* 7 финальных тем */ ]
  }
}
```

## Раунды 1, 2 и 3

- В каждом раунде должно быть **6 категорий**.
- В каждой категории — **5 вопросов**.
- Номиналы:
  - `round1`: 100, 200, 300, 400, 500
  - `round2`: 200, 400, 600, 800, 1000
  - `round3`: 300, 600, 900, 1200, 1500
- Порядок вопросов в категории должен соответствовать порядку номиналов (от меньшего к большему).
- `value` должно быть числом.

### Категория

```json
{
  "name": "Название темы",
  "questions": [ /* 5 вопросов */ ]
}
```

### Вопрос

```json
{
  "value": 300,
  "text": "Текст вопроса",
  "answer": "Правильный ответ"
}
```

Это единственный поддерживаемый формат вопроса. Поля `type`, `theme`, `cost` в паке
не нужны и игнорируются.

### Картинки в вопросе

У вопроса может быть одна или две необязательные картинки:

```json
{
  "value": 300,
  "text": "Что за сооружение на фото?",
  "answer": "Эйфелева башня",
  "images": {
    "question": "images/questions/geography/eiffel-riddle.webp",
    "answer": "images/questions/geography/eiffel-answer.webp"
  }
}
```

- `images.question` — картинка-загадка; показывается вместе с вопросом.
- `images.answer` — картинка-отгадка; показывается только после открытия ответа.
- `images.original` — необязательный оригинал до обработки. Его создаёт редактор
  при нажатии «Изменить»; хранится в WebP. Игра его не показывает и не отправляет
  на ТВ/телефоны.
- Если `images.answer` указывает на тот же файл, что `images.original`, это нормально:
  ответ — чистая картинка без масок.
- Если `images` указан, нужна **хотя бы одна** картинка: `question` или `answer`.
  `original` необязателен. Можно оставить только картинку вопроса или только
  картинку ответа.
- Можно использовать краткую запись строкой или расширенную с alt-текстом:

```json
"images": {
  "question": { "src": "images/questions/geography/eiffel-riddle.webp", "alt": "Металлическая башня на закате" },
  "answer": { "src": "images/questions/geography/eiffel-answer.webp", "alt": "Эйфелева башня" }
}
```

- Путь должен начинаться с `images/` и вести внутрь `questions/images/`.
- Поддерживаются `.png`, `.jpg`, `.jpeg`, `.webp`, `.avif`.
- Файл должен существовать на момент загрузки пака, иначе сервер сообщит об ошибке.
- Для «Кота в мешке» картинки берутся из вопроса банка `questions/cats`;
  для «Аукциона» — из вопроса клетки на табло.

### «Кот в мешке» и «Аукцион»

Эти типы вопросов **не хранятся в паке**: сервер случайно назначает их при загрузке пака.
Количество на раунд задаётся в `game.config.json`:

```json
"specials": {
  "round1": { "cats": { "min": 1, "max": 2 }, "auctions": { "min": 1, "max": 2 } },
  "round2": { "cats": { "min": 2, "max": 2 }, "auctions": { "min": 2, "max": 2 } },
  "round3": { "cats": { "min": 2, "max": 3 }, "auctions": { "min": 2, "max": 3 } }
}
```

- **Кот в мешке:** вопрос передаётся выбранному игроку; отвечает только он.
  Сам вопрос, его тема и ответ берутся из отдельного банка (см. ниже), поэтому
  они не совпадают с вопросом клетки на табло; номинал и ставки — от клетки.
  Порядок показа: сначала ведущий объявляет тему, затем игрок называет одну из
  двух ставок — минимум или максимум раунда, ведущий выбирает её кнопкой в
  панели, и только потом показывается вопрос. Две суммы и подсказка задаются в
  `game.config.json` (`catBet.round1/round2/round3`), по умолчанию — минимальный
  и максимальный номинал вопросов этого раунда. Засчитывается ответ по этой ставке.
- **Аукцион:** номинал — `value`; администратор назначает игрока и ставку
  (не ниже номинала и не выше счёта игрока).
- На табло администратора спецвопросы помечаются рамкой (жёлтой/красной).
  Показ этих пометок на ТВ включается параметром `showSpecialMarkersToTV`.

## Банк вопросов «Кота в мешке»

Вопросы для кота лежат не в паках, а в отдельной папке (по умолчанию
`questions/cats`, путь меняется через `catQuestions.dir` в `game.config.json`).
Можно положить один или несколько JSON-файлов. Формат файла:

```json
{
  "title": "Банк вопросов «Кота в мешке»",
  "questions": [
    {
      "theme": "Космос",
      "text": "Текст вопроса",
      "answer": "Ответ",
      "played": false,
      "images": {
        "question": "images/cats/space-q.webp",
        "answer": "images/cats/space-a.webp"
      }
    },
    { "theme": "История", "text": "Ещё вопрос", "answer": "Ответ", "played": true }
  ]
}
```

Допустим и просто массив вопросов `[{ ... }, { ... }]`. Обязательные поля —
`theme`, `text`, `answer`; поле `played` (`true`/`false`) показывает, сыгран ли
вопрос. Картинки необязательны; если `images` указан, нужна хотя бы одна из
`question`/`answer` — как у обычных вопросов.

- Когда кот открывается, сервер выбирает случайный вопрос со статусом
  `played: false`, ставит ему `played: true` и **сразу сохраняет файл**, поэтому
  статусы не сбрасываются при перезапуске сервера.
- В панели администратора есть карточка «Банк «Кота в мешке»»: всего вопросов,
  сыграно и осталось (по каждому файлу отдельно), а также кнопка
  «Все вопросы — не сыграны» для сброса статусов.
- Раунд не учитывается: вопрос из банка может выпасть в любом раунде.
- Если несыгранных вопросов не осталось, кот не откроется — добавьте вопросы
  или нажмите сброс статусов.
- Если правите файлы вручную, следите за корректностью JSON: комментарии
  читаются, но при сохранении статусов файл перезаписывается без них.

## Финальный раунд

```json
"final": {
  "themes": [
    { "theme": "Космос",   "text": "Текст вопроса", "answer": "Правильный ответ",
      "images": { "question": "images/questions/final/space-q.webp", "answer": "images/questions/final/space-a.webp" } },
    { "theme": "История",  "text": "Текст вопроса", "answer": "Правильный ответ" },
    { "theme": "Литература", "text": "Текст вопроса", "answer": "Правильный ответ" },
    { "theme": "Наука",    "text": "Текст вопроса", "answer": "Правильный ответ" },
    { "theme": "География","text": "Текст вопроса", "answer": "Правильный ответ" },
    { "theme": "Кино",     "text": "Текст вопроса", "answer": "Правильный ответ" },
    { "theme": "Животные", "text": "Текст вопроса", "answer": "Правильный ответ" }
  ]
}
```

Картинки в финальных темах задаются так же, как в обычных вопросах. Картинка вопроса
показывается после открытия финала, картинка ответа — после кнопки «Показать ответ»
в панели ведущего.

- Рекомендуется ровно **7 тем** (как в оригинальной игре).
- Ведущий нажимает на тему в админке, и она скрывается на ТВ и телефонах.
  Когда остаётся одна тема, открывается приём ставок.
- В финале участвуют игроки с положительным счётом. Ставка — от 1 до счёта игрока.
- После показа вопроса игроки могут отправить ответ со своих телефонов; ведущий
  засчитывает верно/неверно, очки меняются на сумму ставки.

Старый формат с одним вопросом продолжает поддерживаться:

```json
"final": { "theme": "Тема", "text": "Текст вопроса", "answer": "Ответ" }
```

Такой пак будет считаться финалом с одной темой (выбор тем в этом случае не нужен).

## Редактор паков

Откройте `/editor.html` — ссылка есть на главной странице и в панели ведущего.

- Редактор доступен только с компьютера, где запущен сервер, если в `game.config.json`
  не задан `editor.token` (или переменная окружения `EDITOR_TOKEN`). Для доступа
  по сети задайте токен и введите его в редакторе.
- Можно создать новый пак, загрузить существующий, импортировать и скачать JSON.
- Для каждой картинки есть кнопка «Загрузить»: файл поворачивается по EXIF,
  уменьшается до `images.maxWidth`×`images.maxHeight` и сохраняется в WebP
  в `questions/images/<имя-пака>/`.
- Рядом с каждой картинкой есть **«Удалить»**: можно оставить только картинку
  вопроса, только картинку ответа или убрать обе.
- У картинки-загадки есть кнопка **«✎ Изменить»**: открывается мини-paint —
  кисть, ластик, прямоугольник, эллипс, линия, цвета заливки/обводки,
  режим **«Мышь»** для перемещения/масштабирования нарисованных объектов
  (выбранный объект удаляется клавишей `Delete` или `Backspace`),
  undo/redo и переключатель «Оригинал». При первом открытии текущая картинка
  вопроса сохраняется как `images.original` в WebP.
- Редактор открывает **текущую картинку вопроса**. Чистый оригинал можно
  посмотреть переключателем «Оригинал».
- Рядом с «Изменить» есть кнопка **«Оригинал в ответ»**: подставляет чистую
  картинку в `images.answer`, не открывая редактор. Если оригинала ещё нет,
  он создаётся из текущей картинки вопроса.
- У картинки-отгадки есть кнопка **«В вопрос»**: копирует её в
  `images.question` и назначает `images.original`; картинка ответа остаётся на
  месте — лишнюю можно удалить кнопкой «Удалить».
- **«Сохранить вопрос»** записывает обработанную картинку в `images.question`.
- **«Сделать чистой картинкой ответом»** подставляет `images.original` в
  `images.answer`. Маски и слои не сохраняются отдельно: при повторном открытии
  загружается текущая `images.question` (с уже нанесёнными масками), а
  `images.original` доступен по переключателю «Оригинал».
- Внешние ссылки (`http://`, `https://`) не поддерживаются: редактор и сервер
  принимают только локальные файлы. Скачайте картинку и загрузите её кнопкой
  «Загрузить» — иначе браузер будет тянуть её из интернета и кэшировать.
- Имя файла формируется автоматически по слоту:
  `r1-c3-q5-question-<hash>.webp`, `r1-c3-q5-answer-<hash>.webp`,
  `final-t2-question-<hash>.webp` и т.п.
- После загрузки картинки не забудьте нажать «Сохранить» — путь записывается в JSON пака.
  При сохранении сервер удаляет старые сгенерированные картинки, на которые больше
  нет ссылок в JSON. Файлы с ручными именами не трогает.
- Вручную картинки можно положить в `questions/images/<имя-пака>/`
  и указать путь в JSON.
- Лимиты задаются в `game.config.json`:
  `images.maxBytes`, `images.maxWidth`, `images.maxHeight`, `images.quality`.
- Редактор работает с паками в `questions/*.json`. Банк «Кота в мешке»
  (`questions/cats`) пока редактируется вручную, но картинки в нём поддерживаются.

## Примечания

- Поля `text` и `answer` — строки (можно использовать `\n` для переноса строки).
- У каждой финальной темы обязательны поля `theme`, `text` и `answer`.
- Значения `text` и `answer` показываются как обычный текст (HTML не поддерживается).
- Ответы и картинки-отгадки никогда не отправляются на ТВ и телефоны до тех пор,
  пока ведущий их не откроет. Текст и картинка-загадка для «Кота в мешке» и
  «Аукциона» также скрыты до показа вопроса.
- Чтобы добавить новый пак, положите `.json` файл в папку `questions/` — он появится
  в списке выбора на панели администратора. То же самое можно сделать через редактор.
