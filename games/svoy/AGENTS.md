# AGENTS.md — «Своя игра»

Самостоятельная игра. Работай только в этой папке.

## Запуск

```bat
npm install
npm start
```

Порт по умолчанию — `8102`, переопределяется через `PORT`. Платформа запускает игру тем же способом. Фронтенд в `public/` не требует перезапуска — только обновление вкладки.

## Структура

| Путь | Что это |
|---|---|
| `server.js` | Express, Socket.IO, комнаты, `/api/health`, `/api/net`, `/qr` |
| `public/index.html` | вход |
| `public/admin.html` | ведущий |
| `public/display.html` | общий экран |
| `public/player.html` | телефон игрока |
| `public/editor.html` | редактор паков и картинок |
| `public/js/` | клиенты, звук, фейерверки, редактор |
| `public/sounds/` | mp3 и `CREDITS.md` |
| `questions/images/` | картинки вопросов (по папкам паков) |
| `public/vendor/fabric.min.js` | локальный Fabric.js для мини-paint |
| `questions/*.json` | паки вопросов |
| `questions/cats/` | вопросы «кота в мешке» |
| `game.config.json` | настройки, JSON с комментариями |
| `QUESTIONS_FORMAT.md` | формат паков |

## Контракт

- `/api/health` → `{ status, game, uptime, rooms }`.
- `/api/net` → LAN-IP и порт.
- `/qr?text=...` → SVG QR.
- `/api/editor/*` → редактор паков; доступ только с localhost или по `editor.token`.
- `/images/questions/*` → картинки вопросов из `questions/images`.
- Socket.IO на стандартном пути `/socket.io/`.
- Клиенты подключаются через `io()` без аргументов.

## Инварианты

- QR на экране должен вести на LAN-IP. `public/js/display.js` берёт адрес из `/api/net` и только при неудаче падает на `location.origin`. Не возвращай `location.origin` как основной вариант.
- Не меняй формат вопросов без обновления `QUESTIONS_FORMAT.md` и существующих паков.
- Картинки вопросов лежат только в `questions/images/...`; путь в паке начинается с `images/`.
- `images.original` — чистая картинка до обработки; она никогда не уходит на ТВ/телефоны.
- Мини-paint не сохраняет слои/маски: при повторном открытии загружается текущая `images.question`, а `images.original` доступен по переключателю «Оригинал».
- `images.answer` может ссылаться на тот же файл, что и `images.original`.
- В `images` может быть только `question` или только `answer`. Если есть только `question`, он показывается и на ответе; если только `answer` — до ответа картинки нет.
- Кнопка «Оригинал в ответ» создаёт `images.original` при необходимости и ставит его в `images.answer`.
- Кнопка «В вопрос» копирует картинку ответа в `images.question`, делает её оригиналом и не меняет `images.answer`.
- В мини-paint есть режим «Мышь» для перемещения/масштабирования; следы ластика не выделяются.
- Ответная картинка и текст вопроса кота/аукциона не уходят на ТВ и телефоны до соответствующего раскрытия.
- После верного ответа вопрос не закрывается автоматически: ведущий закрывает его вручную.
- При показе ответа на ТВ картинка вопроса заменяется картинкой ответа; текст ответа показывается выше текста вопроса. Отдельного блока ответа нет.
- Кнопка «Показать/Скрыть табло на ТВ» переключает на ТВ табло и текущий вопрос, не закрывая вопрос.
- Редактор сохраняет паки атомарно и не должен ломать паки, уже загруженные в комнату.
- При сохранении пака удаляются только старые сгенерированные картинки, не упомянутые в JSON; файлы с ручными именами не трогаются.
- Комнаты в памяти. Постоянного хранилища нет.
- Все паки, звуки, картинки и настройки — внутри папки.
- Никаких импортов из других игр.

## Если появится reverse proxy

Socket.IO сейчас на дефолтном пути. При монтировании в подпуть придётся синхронно поменять:

- сервер: `new Server(server, { path: '...' })`;
- клиенты: `io({ path: '...' })`;
- ассеты в HTML: сейчас абсолютные `/js/...`, `/css/...`, `/sounds/...`.

Без этого path-прокси сломает игру. Это отдельное архитектурное решение, а не мелкая правка.
