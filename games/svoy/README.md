# Своя игра (веб-версия)

Игра по мотивам «Своей игры» на Node.js + Express + Socket.IO.

## Возможности
- **Администратор (ноутбук, создатель комнаты):** создаёт комнату, выбирает файл с вопросами, запускает раунды, открывает вопросы на табло, управляет кнопкой ответа (buzz), видит правильные ответы и засчитывает/снимает очки, управляет «Котом в мешке», «Аукционом» и финалом.
- **Экран для ТВ (отдельная вкладка/окно):** открывается администратором, показывает табло, текущий вопрос, кто нажал первым, очки всех игроков и проигрывает звуки игры (звук есть только на ТВ).
- **Игроки (телефоны):** подключаются из списка активных комнат, видят свой счёт и кнопку «Я отвечаю!» (показывает на ТВ/админке, кто нажал первым). Ответы даются устно в комнате.
- **Паки вопросов:** хранятся в JSON-файлах в папке `questions/`, администратор выбирает нужный файл перед игрой.

> Обычно используется одна комната/игра за раз (поддерживается модель комнат со списком на главной).

## Запуск

```bash
npm install
npm start
```

Откройте в браузере: `http://localhost:8102`

- На главной странице админ создаёт комнату → автоматически открывается панель администратора.
- В панели администратора есть ссылка **«Открыть экран для ТВ»** (откройте в отдельной вкладке/окне и выведите на телевизор).
- Игроки открывают главную страницу, вводят ник, выбирают комнату из списка и подключаются.

Если играют с разных устройств в одной сети, используйте IP-адрес компьютера с сервером, например `http://192.168.x.x:8102`.

## Формат вопросов

Подробное описание формата: [`QUESTIONS_FORMAT.md`](QUESTIONS_FORMAT.md)  
Пример пака: [`questions/sample.json`](questions/sample.json)

Кратко: JSON содержит `title`, `round1`, `round2`, `round3` (по 6 категорий × 5 вопросов)
и `final` с массивом из 7 тем. Каждый вопрос — это `{ "value": 300, "text": "...", "answer": "..." }`.
Номиналы: 1 раунд — 100–500, 2 раунд — 200–1000, 3 раунд — 300–1500.

«Кот в мешке» и «Аукцион» **не хранятся в паке** — сервер случайно назначает их при
загрузке пака, а количество задаётся в `game.config.json`.

Чтобы добавить новый пак, положите `.json` файл в папку `questions/` — он появится в списке выбора в админ-панели. При загрузке пак проверяется на корректность структуры.

### Картинки и редактор паков

У вопроса может быть одна или две необязательные картинки: `images.question`
(загадка) и `images.answer` (отгадка). Любую из них можно удалить отдельно.
Подробности — в [`QUESTIONS_FORMAT.md`](QUESTIONS_FORMAT.md).
У картинки-загадки есть кнопка **«✎ Изменить»**: мини-paint с кистью, ластиком,
фигурами, цветами и заливкой. Редактор открывает текущую картинку вопроса; чистый
оригинал доступен по переключателю «Оригинал». При первом редактировании оригинал
сохраняется в `images.original` (WebP), а кнопка **«Сделать чистой картинкой ответом»**
подставляет его в `images.answer`. Рядом с «Изменить» есть **«Оригинал в ответ»** —
она делает то же самое без открытия редактора и при необходимости создаёт оригинал.
В мини-paint есть режим **«Мышь»** для перемещения и масштабирования нарисованных
объектов, а рядом с каждой картинкой — кнопка **«Удалить»**. У картинки ответа есть
кнопка **«В вопрос»** — она копирует ответную картинку в вопрос, не удаляя её из ответа.

Для визуального редактирования откройте `/editor.html` (ссылка есть на главной и в
админ-панели). Редактор умеет создавать и сохранять паки, загружать картинки,
сжимать их в WebP и записывать пути в JSON. При сохранении пака старые
неиспользуемые сгенерированные картинки удаляются автоматически; файлы с ручными
именами не трогаются. По умолчанию редактор доступен только
с компьютера, где запущен сервер; для доступа по сети задайте `editor.token`
в `game.config.json` или переменную окружения `EDITOR_TOKEN`.

## Настройки

Все параметры находятся в `game.config.json` (можно использовать комментарии `//` и `/* */`):

- `port` — порт сервера (переопределяется переменной окружения `PORT`);
- `questionsDir` — папка с паками вопросов;
- `specials.round1/round2/round3.cats/auctions` — сколько «Котов» и «Аукционов» случайно назначать в каждом раунде;
- `catBet.round1/round2/round3.min/max` — две допустимые ставки в «Коте в мешке»
  (ставка может быть только минимумом или максимумом; по умолчанию `null` — берутся
  минимальный и максимальный номинал вопросов этого раунда);
- `catBet.round1/round2/round3.note` — текст-подсказка, который показывается на ТВ и телефонах
  (плейсхолдеры `{min}` и `{max}` подставляются автоматически);
- `catQuestions.dir` — папка с банком вопросов для «Кота в мешке» (по умолчанию `questions/cats`);
- `editor.token` — токен для доступа к редактору паков по сети (пусто — только с компьютера сервера);
- `images.maxBytes/maxWidth/maxHeight/quality` — лимиты и качество сжатия картинок в редакторе;
  каждый вопрос банка имеет статус «сыгран», который сохраняется в файле;
- `game.allowPlayersReconnect` — разрешать игрокам переподключаться и сохранять счёт;
- `game.showSpecialMarkersToAdmin` — показывать пометки спецвопросов админу;
- `game.showSpecialMarkersToTV` — показывать пометки спецвопросов на ТВ;
- `game.autoCloseQuestionOnCorrect` — автоматически закрывать вопрос при верном ответе
  (по умолчанию `false`: вопрос и картинка ответа остаются на экране, пока ведущий не нажмёт «Закрыть вопрос»);
- `sound.enabled` — включать звуки (звучат только на экране ТВ);
- `sound.volume` — общая громкость 0…1;
- `sound.events` — какой файл и с какой громкостью играть в каждом сценарии
  (`roundStart`, `questionOpen`, `cat`, `auction`, `buzz`, `correct`, `wrong`, `final`, `finish`).
  Файлы лежат в `public/sounds/`, список лицензий — `public/sounds/CREDITS.md`.
  Заменять mp3 можно на ходу: ссылка на файл содержит версию по времени изменения,
  поэтому сервер сам сообщит ТВ о новой версии (достаточно, чтобы вкладка ТВ была открыта;
  при необходимости обновите её).

Файл читается один раз при запуске сервера: после изменения настроек перезапустите
`npm start`.

## Игровой процесс (реализовано)

- Классическая структура: 1 раунд, 2 раунд, 3 раунд, финал.
- Табло 6×5 с номиналами (раунд 1: 100–500, раунд 2: 200–1000, раунд 3: 300–1500).
- **Buzz:** админ открывает приём нажатий, на экранах показывается, кто нажал первым. Админ отмечает «Верно/Неверно» (очки +/- номинал или указанная сумма). При неверном ответе buzz можно открыть снова для остальных.
- **Кот в мешке:** админ выбирает игрока, которому передаётся вопрос; отвечает только он. Вопрос берётся из отдельного банка (`questions/cats`), поэтому тема и текст всегда отличаются от клетки на табло, а использованный вопрос помечается сыгранным. Порядок: сначала на ТВ объявляется тема, затем игрок называет одну из двух допустимых ставок — минимум или максимум раунда (по умолчанию 100/500 в 1 раунде, 200/1000 во 2-м, 300/1500 в 3-м), админ выбирает озвученную кнопкой в панели, и только после этого показывает вопрос. По выбранной ставке и засчитывается ответ. В панели админа видно, сколько вопросов банка сыграно и осталось, и есть кнопка сброса статусов.
- **Аукцион:** админ назначает игрока и ставку (от номинала до счёта игрока), затем засчитывает результат по ставке.
- **Финал:** ведущий по одной убирает темы (в паке их 7) — на ТВ и телефонах остаются только неубранные. Когда осталась одна тема, игроки с положительным счётом отправляют ставки; после показа вопроса могут отправить ответ (для ведущего). Админ засчитывает верно/неверно по ставкам.
- **Звуки:** играют только на экране ТВ; сценарии и файлы настраиваются в `game.config.json`.
- **Завершение игры:** кнопка «Завершить игру» в панели админа. На ТВ появляется экран итогов: игроки с максимальным счётом (при ничье — все), их очки и салют; играет финальный звук (`finish`). В админ-панели показывается карточка с победителями и итоговой таблицей, на телефонах — сообщение о завершении игры и победителях.
- Счёт можно корректировать вручную в таблице игроков (админ-панель).

## Примечания / допущения

- Админ — тот, кто создал комнату (отдельный человек с ноутбуком). Доступ подтверждается токеном, который хранится в `sessionStorage` вкладки; при очистке данных вкладки управление комнатой восстановить нельзя — создайте новую комнату.
- Игрок при переподключении подтверждает личность токеном из `sessionStorage`; чужой счёт/ников не перехватывается.
- Игроков может быть больше трёх: все отображаются на экране и имеют собственный счёт; в финале участвуют все с положительным счётом.
- Состояние игры хранится в памяти сервера (при перезапуске сервера комнаты сбрасываются).
- Интерфейс и контент рассчитаны на русский язык.
